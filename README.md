# Ashfaqul Haq

Personal site &amp; writing — offensive security engineering, web &amp; mobile penetration testing,
and field notes from engagements.

## What's here

- **Home** — quick introduction, current focus, latest writeup.
- **Blog** — long-form writeups grouped by category: web exploitation, mobile pentest, CVE disclosures.
- **Projects** — published CVEs and academic publications.
- **CV** — current curriculum vitae with downloadable PDF.
- **Contact** — channels for engagement, advisory, and CVE coordination.

## Stack

Jekyll · GitHub Pages · custom theme. No JavaScript frameworks, no build pipeline.

The visual design has two themes (dark, light) with a click toggle in the rail.
The dark theme is the default cyber-grid look; the light theme is a warmer
neo-brutalist palette.
